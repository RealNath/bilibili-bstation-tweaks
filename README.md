# Bilibili.tv Watermark Hider, Subtitle Toggles and Cycle

This is a userscript to toggle hide/show watermark and subtitles in bilibili.tv (since the site doesn't provide hiding subtitles for some reason), as well as switching through a list subtitles.

## Shortcuts

These shortcuts and watermark hide/show can be changed on the top of the code, but the default is:
* `c`: toggle between hiding/showing subtitles
* `v`: switch to the next subtitle language in the list (and back to the first from last)
* `shift+v`: switch to the previous subtitle language in the list (and back to the last from first)

## Installation

Note: as this is a userscript, it only works for the web version of bilibili.tv. Mobile app is unsupported.

1. Install Tampermonkey
2. Install the userscript from one of these URLs:
    * GitHub: https://raw.githubusercontent.com/RealNath/bilibili-subtitle-hider-and-cycle/refs/heads/main/bilibili-subtitle-watermark-tweaks.user.js
    * Greasy Fork: https://greasyfork.org/en/scripts/600322-bilibili-tv-watermark-hider-subtitles-hider-and-cycle
